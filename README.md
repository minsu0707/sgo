# sgo

> 터미널에서 바로 즐기는 스무고개 게임

설치 없이, 명령어 한 줄이면 바로 시작할 수 있어요.

```
npx minsu0707/sgo
```

## 미리보기

실제 실행 화면은 색이 들어간 화려한 배너로 뜨지만, 여기서는 어떤 환경에서도 깨지지 않도록 단순한 글자로만 표현했어요.

```
  ____   ____  ___
 / ___| / ___|/ _ \
 \___ \| |  _| | | |
  ___) | |_| | |_| |
 |____/ \____|\___/

        W E L C O M E   T O   S G O
        스무고개에 오신 걸 환영합니다

           Press ENTER to start
```

## 어떻게 노는 건가요?

시작하면 두 가지 방식 중 하나를 고를 수 있어요.

| 방식 | 설명 |
|---|---|
| 1. 내가 맞히기 | 컴퓨터가 단어를 하나 정해요. 문장으로 자유롭게 질문을 입력하면(예: "동물인가요?"), 컴퓨터가 키워드를 인식해서 예/아니오로 답해요. |
| 2. 컴퓨터가 맞히기 | 내가 마음속으로 무언가를 하나 떠올려요. 컴퓨터가 예/아니오 질문을 던지며 알아맞혀요. |

두 방식 모두 **질문은 최대 20개**까지만 할 수 있어요. 그 안에 못 맞히면 게임 종료!

## 요구 사항

- Node.js 18 이상

## 직접 빌드해서 실행하고 싶다면

```
git clone https://github.com/minsu0707/sgo.git
cd sgo
npm install
npm run dev
```
