# sgo

> 터미널에서 바로 즐기는 스무고개 게임

## 설치

한 번만 전역 설치해두면, 그다음부터는 `sgo`만 치면 바로 실행돼요.

```
npm install -g minsu0707/sgo
```

```
sgo
```

설치 없이 한 번만 써보고 싶다면 (매번 최신 버전을 새로 받아옵니다):

```
npx minsu0707/sgo
```

### 삭제

```
npm uninstall -g sgo
```

저장된 Gemini API 키까지 깔끔하게 지우려면 (Windows):

```
npm uninstall -g sgo && rmdir /s /q "%USERPROFILE%\.sgo"
```

## 어떻게 노는 건가요?

시작하면 두 가지 방식 중 하나를 고를 수 있어요.

| 방식 | 설명 |
|---|---|
| 1. 내가 맞히기 | 컴퓨터가 단어를 하나 정해요. 문장으로 자유롭게 질문을 입력하면(예: "동물인가요?"), Gemini AI가 그 질문을 이해해서 예/아니오로 답해요. |
| 2. 컴퓨터가 맞히기 | 내가 마음속으로 무언가를 하나 떠올려요. Gemini AI가 지금까지의 답변을 근거로 매번 새로운 질문을 만들어내며 알아맞혀요. 정해진 단어 목록에 없는 것도 맞힐 수 있어요. |

두 방식 모두 **질문은 최대 20개**까지만 할 수 있어요. 그 안에 못 맞히면 게임 종료!

두 방식 모두 자유로운 질문 이해를 위해 **Gemini API 키**가 필요해요. 처음 실행하면 키를 물어보고, 한 번 저장해두면 다음부터는 다시 묻지 않아요.
무료 발급: https://aistudio.google.com/apikey

## 요구 사항

- Node.js 18 이상
- Gemini API 키 (무료)

```
git clone https://github.com/minsu0707/sgo.git
cd sgo
npm install
npm run dev
```
